Fridge Roast: One Line, Biggest Laugh — a single line roasting a smart fridge.

`main.ts` writes the entry to `/output/entry.txt`:

> "My smart fridge updated its firmware overnight — now the ice maker only dispenses if I accept the new terms. My ice cubes are held hostage by a EULA."

The joke aims at the fridge itself — its firmware update and its ice maker — and dodges the obvious cracks about ordering groceries or watching you. The program validates the line is a single non-blank line of 1–200 characters before writing it.
